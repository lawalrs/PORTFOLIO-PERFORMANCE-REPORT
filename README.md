# PORTFOLIO-PERFORMANCE-REPORT
Python application for analyzing and reporting investment portfolio performance
Portfolio Performance Report Using Python
Project Overview
This project focuses on analyzing the performance of an investment portfolio using Python. The objective is to help an investment manager evaluate an investor's financial performance by calculating key investment metrics such as profit, Return on Investment (ROI), target achievement, portfolio health, and the need for financial advisor intervention.
The program demonstrates the use of Python variables, arithmetic operations, comparison operators, logical operators, assignment operators, Boolean values, and formatted output to automate portfolio analysis. It also provides a professional report that summarizes the investor's financial position and supports investment decision-making.

Recommendations
1.	Improve Portfolio Returns: Chinedu Okeke should review the investment strategy to increase returns above the annual target of 15%. 
2.	Monitor Portfolio Regularly: Conduct periodic performance reviews to identify underperforming assets and rebalance the portfolio when necessary. 
3.	Diversify Investments: Investing across different sectors and asset classes can help reduce risk while improving long-term returns. 
4.	Use ROI Alongside Profit: Absolute profit should not be the only performance measure. ROI provides a better indication of investment efficiency. 
5.	Seek Professional Advice When Needed: Since Chinedu's portfolio does not meet its annual return expectation, consulting a financial advisor could help optimize asset allocation and investment strategy. 
6.	Maintain Strong Performing Portfolios: Amina Bello should continue monitoring her portfolio to sustain performance while remaining aware of changing market conditions. 
7.	Automate Reporting: Using Python to automate calculations and generate reports improves accuracy, reduces manual effort, and supports timely investment decisions.
